# forgejo-runner

> Fork of [dariogriffo/forgejo-runner-debian](https://github.com/dariogriffo/forgejo-runner-debian) (MIT); the original packaging is by Dario Griffo. Served at [deb.gaofn.xyz](https://deb.gaofn.xyz) for Debian 12 (bookworm) and 13 (trixie).

forgejo-runner is the task runner for Forgejo Actions, the CI/CD system
built into Forgejo. It registers against a Forgejo instance and executes
the workflow jobs it is assigned.

See https://code.forgejo.org/forgejo/runner and
https://forgejo.org/docs/latest/admin/actions/ for documentation.
